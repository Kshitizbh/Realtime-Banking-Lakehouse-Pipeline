## Went wrong
(Full details in `docs/troubleshooting.md`.)
1. `.wslconfig` was saved as `.wslconfig.txt` by Notepad, so WSL ignored it (`nproc` still showed 32). Fixed by writing the file with PowerShell.
2. VS Code opened the Ubuntu folder as a `\\wsl.localhost` network path. Fixed with the WSL extension and `code .` from Ubuntu.
3. Ran commands in the old `/mnt/d/...` copy instead of `~/projects/...`. Moved back to the Ubuntu copy.
4. `make venv` failed because Ubuntu's Python 3.14 had no `venv` package. Fixed with `sudo apt install -y python3.14-venv`.
5. Typo in the persistence test: created `presist_check`, tried to delete `persist_check`, and got a 404.
6. `docker compose down` did nothing, because every service is in a profile. Fixed with `--profile "*"` (`make down`).
7. `make stop` failed with "No rule to make target 'stop'": the target didn't exist.
